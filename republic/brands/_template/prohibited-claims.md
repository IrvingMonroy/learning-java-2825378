# Prohibited claims

Copy that contains any of these fails Writing QA item 7 and is never published.

- Medical cure/treatment/diagnosis language unless licensed scope explicitly allows the exact phrasing
- Guaranteed outcomes or timelines
- Comparisons naming competitors
- Before/after imagery without consent on file
- Income or results claims without documented proof
- Platform-policy-sensitive terms: <list per platform>
