# Reputation flow

Classification (worker tier `local`):
- **good** — positive, no complaint → reply draft
- **neutral** — mixed or factual → reply draft
- **sensitive** — health outcome complaint, refund/legal language, staff conduct,
  identifiable third party, minor mentioned → owner alert only; no draft posted

Reply drafts: Writing System, BRAND WRITING mode, ≤ 60 words, thank by first name if
public, never restate the complaint, never make a medical or outcome claim
(`prohibited-claims.md`).

Extraction (every review, any class): quotes of how the customer describes the
problem, the service, and the result → Librarian as `evidence/voice-of-customer`
with source, date, rating.

Operational intelligence: a negative theme recurring 3+ times in 90 days opens an
`ops` card titled with the theme and the quotes.
