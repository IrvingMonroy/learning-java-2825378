# Last 30 Days — one intelligence pass, many outputs

Platforms never independently research the same subject. (SPEC §3)

## Procedure
1. Frame one question from the job's intake and `video-analysis.md` topics.
2. Run Last 30 Days for the topic and brand niche. Record the run date.
3. Add customer language the existing profile already holds (reviews, DMs, comments,
   objections) as verbatim, sourced quotes. Worker tier `local` for extraction.
4. Write a **Research Brief** on the job (`references/research-brief.md` shape): Question ·
   Current intelligence (dated) · Customer language (quoted, sourced) · Competitor
   observations · Content opportunities as evidence, not copy · Gaps and cautions ·
   Sources. Mark `current-intel: missing` if the tool was unavailable; never fabricate
   recency.
5. Hand to the existing strategy step.

## Boundaries
- Produces evidence, never posts, hooks, or captions. Never publishes or approves.
- Never touches the existing intake or strategy logic; it attaches a brief and hands back.
- Never decides objective or platforms.
- Every claim carries a source line or `inference`.
