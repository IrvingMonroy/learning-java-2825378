# Instagram — native presentation norms

- Formats: Reel (primary), carousel, single image, Story.
- Reels: hook in first 1–2s, visual demonstration beats talking head; 15–45s default.
- Caption: first line carries the hook again; line breaks; hashtags 3–8, niche over broad.
- Alt text on every image. Location tag for local brands (Physically Meta).
- Comment-to-DM keyword goes in the caption and the first pinned comment.
