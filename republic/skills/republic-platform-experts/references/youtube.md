# YouTube — native presentation norms

- Formats: Short (vertical, <60s) and long-form (chaptered).
- Title is a search query first, curiosity second. Thumbnail spec to production.
- Description: first 2 lines carry the promise; chapters with timestamps; links.
- Tags 5–15; end card and pinned comment planned in the brief.
- Long-form: demonstration-first opening, then structure; cold open beats intro.
