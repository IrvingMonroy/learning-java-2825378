# Stage C — Angle generation

Question: *What credible reasons would different segments of this audience care?*

Sources (each angle cites at least one): reviews · DMs · comments · search intent
clusters · sales conversations · customer questions · actual offer characteristics.

Procedure:
1. List candidate reasons, one per line, each with a source.
2. Segment by audience (from `audience.md`).
3. Cluster into 3–7 motivations. Name each motivation in the customer's own words where possible.
4. Rank by evidence strength, not by how clever it sounds.
5. Discard unsourced angles. Do not pad to a number.

Output: `angles.md` on the card with `{id, motivation, segment, sources[], strength}`.
