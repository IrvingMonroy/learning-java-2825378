# Stage D — Direct response (SELL · BOOK · OPT-IN · CONVERT)

Runs only when STRATEGY set the objective to a conversion goal.

- One offer, from `offers.md`. One action.
- Hook from the ranked angles (Stage C), grounded in a real motivation.
- Proof from `proof.md` only. Objections handled from `objections.md` only.
- Every claim cross-checked against `prohibited-claims.md`.
- CTA states the exact next step and what the person gets. Comment-to-DM keyword, if
  used, is registered with `republic-distribution` before publishing.
- Still passes Writing QA: it must sound like this person selling, not a template.
