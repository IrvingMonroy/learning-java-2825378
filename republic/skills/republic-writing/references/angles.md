# Angles / motivations (from 72 Reasons to Buy)
Ask: what credible reasons would different segments of this audience care?
1. List candidate reasons, each with a source (review, DM, comment, search cluster, sales
   conversation, customer question, offer characteristic).
2. Segment by the profile's audience segments.
3. Cluster into 3–7 motivations, named in the customer's words where possible.
4. Rank by evidence strength. Drop unsourced angles. Never pad to a number.
Output `angles.md`: `{id, motivation, segment, sources[], strength}`.
